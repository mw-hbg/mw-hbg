# Hi, I'm mw-hbg 👋

[English](#english) · [Deutsch](#deutsch)

## English

I'm not a developer by trade, just a hobbyist with an ever-growing smart home.
My setup combines **Home Assistant**, **KNX**, **Shelly**, **Zigbee** and a **solar + heat pump system**.
I want the tech to help in everyday life without needing constant attention, so I build the pieces I can't find off the shelf.

### Why I do this
- **Curiosity:** I like understanding how things work, and then making them better.
- **Everyday life:** Good automation is the kind you barely notice. It just works.
- **Sharing:** I've learned a lot from the community, so I share what works well for me.

### How I build
- **Security first:** only the access that is really needed – no Home Assistant API access, no privileged mode.
- **Easy setup:** everything through the Home Assistant UI.
- **English and German:** documentation and interface in both languages.

## Deutsch

Ich bin kein Entwickler von Beruf, sondern Hobbybastler mit einem stetig wachsenden Smart Home.
Bei mir arbeiten **Home Assistant**, **KNX**, **Shelly**, **Zigbee** und eine **PV-Anlage mit Wärmepumpe** zusammen.
Die Technik soll im Alltag helfen, ohne ständig Aufmerksamkeit zu brauchen – deshalb baue ich, was es so nicht fertig gibt.

### Warum ich das mache
- **Neugier:** Ich will verstehen, wie Dinge funktionieren – und sie dann besser machen.
- **Alltag:** Gute Automation merkt man kaum. Sie funktioniert einfach.
- **Teilen:** Ich habe viel von der Community gelernt, also teile ich, was bei mir gut funktioniert.

### Wie ich baue
- **Sicherheit zuerst:** nur der Zugriff, der wirklich nötig ist – kein Zugriff auf die Home-Assistant-API, kein privilegierter Modus.
- **Einfache Einrichtung:** alles über die Oberfläche von Home Assistant.
- **Deutsch und Englisch:** Anleitung und Oberfläche in beiden Sprachen.
